# Investigation Panel — Central 24-HR Clinic

Single-page clinic reference for ordering investigations and quoting patient prices (before GST).

- **Blood:** Pathlab, Innoquest and Lucence panels and single tests, searchable by ICD-10 diagnosis, with the cheapest panel option per lab and a Pathlab vs Innoquest comparison.
- **Imaging:** AsiaMedic (X-ray) and RadLink (X-ray, ultrasound, mammogram, CT, MRI, BMD, PET, biopsy) price lists, with a tick-to-total order builder.

Open `index.html` in a browser; it has no build step or dependencies.

Price sources: Pathlab 2025 catalogue (v240725), Innoquest 2026 catalogue, Lucence 1 Oct 2026 list, AsiaMedic 1 Jan 2026 list, RadLink January 2026 edition.

> This public version contains patient sell prices only (before GST). Lab and imaging cost prices are not included anywhere in the file.
